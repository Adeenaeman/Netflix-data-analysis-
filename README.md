Netflix Data Analysis using Python
Project Overview

This project analyzes the Netflix Movies and TV Shows dataset using Python. The objective is to explore the dataset, clean missing values, perform exploratory data analysis (EDA), create visualizations, and practice Pandas and NumPy operations.

Dataset

Source:
https://www.kaggle.com/datasets/shivamb/netflix-shows

Dataset contains information such as:

Title
Type (Movie / TV Show)
Director
Cast
Country
Release Year
Rating
Date Added
Genre
Description
